A jailbreak has layers.

An entry point opens an app or browser. A kernel exploit grants deeper access. A homebrew enabler adds usable features. A PS5 hypervisor exploit is another, separate layer.

A few common questions.

Does “homebrew available” mean everything works?

No. It means the cited projects document a compatible route and homebrew enabler. Features, stability, game support, console model requirements, and rest mode can differ. Check the linked project notes for your exact setup.

Is “not verified” the same as “not jailbreakable”?

No. This is a curated snapshot, not proof that no exploit exists. Unlisted, newly released, or older versions may need additional research. We do not turn an unsupported guess into a yes or no.

Does this website jailbreak my console?

This site checks compatibility and explains documented options. It does not run exploits on your console. The project links open documentation, where you can review the requirements.

Does this information update automatically?

This edition was reviewed on 12 October 2026. It is a manually reviewed snapshot and does not fetch live compatibility data. Source links lead to the current project pages.

Does the console model matter?

Yes. Firmware is the first check; entry-point requirements still matter. A Blu-ray method requires a usable disc drive, and an app-based method can require a specific app version or installation process. An old firmware listed here may never have shipped on a newer console model.

Our verification approach

Records are based on maintainer documentation and release notes, not hands-on console testing. We match explicit firmware lists where available; where a maintainer documents a range, we list known releases in that range. A homebrew result combines a documented exploit route with enabler support. A kernel exploit alone receives its own label. Documentation can lag behind releases, and this database is not exhaustive.

PS5 hypervisor support is only claimed where ps5-hen explicitly documents it. Relapse compatibility follows its source-code allowlist, including gaps in its headline range. PS4 13.52 is supported by a public browser route and GoldHEN beta. The newer PS5 11.00–13.60 records combine Relapse with the community etaHEN Unified port; they do not imply upstream etaHEN feature parity or hypervisor defeat.
